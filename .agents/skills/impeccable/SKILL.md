# Impeccable Design Guidelines

Based on [pbakaus/impeccable](https://github.com/pbakaus/impeccable).

## Core Principles
1. **Defeat AI Cliché**: Avoid generic flat cards, oversized purple gradients, or unconsidered spacing.
2. **Intentional Contrast & Hierarchy**: Every screen needs a clear visual focal point. Use weight, opacity, and scale deliberately.
3. **Typography Craft**: Pair monospaced tactical counters and telemetry with clean, legible sans-serif headers and data tables.
4. **Restraint & Polish**: Micro-borders (1px with subtle alpha), soft inner glows, and consistent radius tokens.
5. **Dynamic State Representation**: Normal, Warning, Fault, and Recovery states must have distinctive visual signatures and feedback.
