# Onyx RAG & Reasoning Guidelines

Based on [onyx-dot-app/onyx](https://github.com/onyx-dot-app/onyx).

## Grounded Agent Reasoning
1. **Evidence Attribution**: Incidents and anomaly detections cite grounded timeline markers, metric deltas, and telemetry sources.
2. **Interactive Postmortems**: Collapsible analysis sections, actionable remediation recommendations, and resilience scoring breakdown.
3. **Conversational Command Deck**: Clear agent log output with typewriter effect and status telemetry.
