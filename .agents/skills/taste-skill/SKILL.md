# Design Taste & Polish Guidelines

Based on [leonxlnx/taste-skill](https://github.com/leonxlnx/taste-skill).

## Design System Tokens
- **Backgrounds**: Deep, rich layers (`#030712`, `#0b0f19`, glassmorphic surfaces with `backdrop-blur-md`).
- **Borders & Dividers**: Subtly luminous borders (`border-white/10`, `border-cyan-500/20`), avoiding harsh opaque lines.
- **Micro-accents**: Tactical neon highlights (electric cyan `#00f0ff`, radar amber `#f59e0b`, emergency crimson `#ef4444`, system green `#10b981`).
- **Interactive Feedback**: Hover lifts, radial cursor spotlighting, smooth color interpolations.
