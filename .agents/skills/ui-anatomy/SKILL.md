# UI Anatomy Guidelines

Based on [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy).

## Component Structure
- Header: Icon + Title + Status Pill + Quick Action.
- Body: Dynamic content with responsive layout and empty/loading states.
- Footer: Contextual telemetry, timestamp, or pagination.
- States: Default, Hover, Active, Focus-Visible, Fault/Alert, Loading, Disabled.
